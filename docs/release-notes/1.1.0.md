The first public release of **Multi-Stream Stats**: a dock with live statistics for every streaming destination (OBS's own stream, each Aitum Multistream destination, other plugins' outputs) plus OBS's rendering, encoding and system performance.

**Requires OBS Studio 33.** Not affiliated with the OBS Project or Aitum.

## Which file do I need?

| Your computer | Download |
|---|---|
| Windows 10/11, 64-bit | **`obs-multistream-stats-1.1.0-windows-x64-installer.exe`** (works for standard and portable OBS), or `…-windows-x64-manual.zip` to copy the files yourself |
| Ubuntu 26.04, x86_64 | **`obs-multistream-stats_1.1.0_ubuntu-26.04_amd64.deb`** (for OBS Studio 33 from the official OBS PPA) |
| Other Linux, x86_64 | `obs-multistream-stats-1.1.0-linux-x86_64-manual.tar.xz` (per-user install; tested on Ubuntu 26.04 only) |
| macOS | Not available. macOS support is planned for a future release. Development and compatibility testing are not yet complete. No release date is currently available. |
| OBS from Flatpak | Not supported yet |

The source code is attached as `obs-multistream-stats-1.1.0-source.tar.xz`.

## Install

Close OBS first.
- **Windows:** run the installer and choose *Standard OBS Studio* or *Portable OBS Studio folder*.
- **Ubuntu 26.04:** `sudo apt install ./obs-multistream-stats_1.1.0_ubuntu-26.04_amd64.deb`
- **Other Linux:** extract the archive and copy the `obs-multistream-stats` folder into `~/.local/share/obs-studio/plugins/` (steps in the archive's `INSTALL.txt`).

Then open **Docks → Multi-Stream Statistics**. Full instructions, manual installation, uninstalling and troubleshooting: [INSTALL.md](https://github.com/{REPOSITORY}/blob/v1.1.0/INSTALL.md).

**Not code-signed yet.** Windows SmartScreen: *More info → Run anyway*. The Linux packages are not GPG-signed; compare them with the SHA-256 checksums below. Details in INSTALL.md.

## What's in 1.1.0

- Windows x64 packages: installer and manual ZIP. The Windows DLL is exactly the file that passed the isolated regression and installer tests.
- Linux x86_64 packages: a `.deb` for Ubuntu 26.04 and a manual `.tar.xz`, built and tested on Ubuntu 26.04 by the project's automated builds.
- Only active outputs are listed; OBS's own stream always is. A *Last failure* line keeps the reason when a destination drops out.
- The dock adapts to its shape: stacked when tall, a native-style table when wide.

Full list: [CHANGELOG.md](https://github.com/{REPOSITORY}/blob/v1.1.0/CHANGELOG.md).
What was verified on each platform: [COMPATIBILITY.md](https://github.com/{REPOSITORY}/blob/v1.1.0/COMPATIBILITY.md).

## Known limitations

- OBS Studio 33.x only. Linux is tested on Ubuntu 26.04 only, in automated tests on virtual machines. Windows on ARM, Linux ARM64 and Flatpak are not supported.
- macOS support is planned for a future release. Development and compatibility testing are not yet complete. No release date is currently available.
- Outputs that exist for less than 250 ms are not seen; SRT/RIST/WHIP outputs report no dropped frames (OBS limitation).
- English only.
- More in the [README](https://github.com/{REPOSITORY}/blob/v1.1.0/README.md#known-limitations).
